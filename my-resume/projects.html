แขนกลหุ่นยนต์ควบคุมด้วย Flex Sensor และ Arduino

เขียนโปรแกรม Arduino เพื่อควบคุมเซอร์โวมอเตอร์ ทดสอบและปรับเทียบเซนเซอร์ เพื่อให้สามารถตรวจจับการเคลื่อนไหวของนิ้วมือ พร้อมเชื่อมต่ออุปกรณ์ฮาร์ดแวร์ และแก้ไขปัญหาของระบบ

  • Arduino
  • Flex Sensor
  • Servo Motor

  • Python
  • Raspberry Pi
  • GPIO
